### ⚡ &nbsp;Projects

- **[git-quill](https://github.com/tonklasocute/git-quill)** (Go): writes commit messages, PR descriptions, changelogs and reviews from your git diff. Runs locally with Ollama and redacts secrets. `brew install --cask tonklasocute/tap/git-quill`
